Security and reliability built into the platform.

DebutDeploy applies platform-level controls across networking, secrets, backups, access and service monitoring. Security controls are designed around industry-standard practices; we publish certifications only once they are genuinely held.

Workload isolation

Every application and database runs in its own fully isolated container with clean resource boundaries. Dedicated plans do not co-tenant CPU.

Secret management

Environment secrets are encrypted at rest and become write-only after saving. Our upstream infrastructure credentials never reach your browser or your repository.

Encryption

All traffic is served over HTTPS with certificates issued automatically via Traefik. There are no plaintext endpoints.

Backups

Managed Postgres is backed up nightly with 7-day retention. Platform configuration is backed up on the same schedule.

Access and tokens

Sign in with GitHub or Google. API tokens are scoped read-only or full, revocable, with per-resource ownership checks.

Least-privilege deploys

Repository access uses a single read-only deploy key, requesting only the GitHub scopes needed to build and deploy.

Monitoring and incidents

Service health is checked continuously and incidents are published to the status page as they are investigated.

Data location

Compute and storage run in data centres in Germany and Finland, inside the EU. No customer data is processed outside the region without notice.
